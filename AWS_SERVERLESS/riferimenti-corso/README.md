# ACA-Serverless-AWS

**Serverless su AWS** - Materiali completi del corso per costruire applicazioni serverless su Amazon Web Services con Lambda, API Gateway, DynamoDB, Step Functions e SAM.

## 📖 Argomenti trattati

Questa repository contiene materiali didattici completi per un corso sul **serverless computing su AWS**, con laboratori pratici pensati per imparare il cloud computing facendo. Le lezioni 10-19 formano un blocco di 40 ore, composto da dieci sessioni di 4 ore. Il corso copre l'intero stack serverless, dalle basi del Green IT fino all'orchestrazione reale e all'Infrastructure as Code.

1. Green IT - Smart Working, Smart Grid, economia circolare
2. Introduzione al serverless computing e alle architetture cloud-native
3. Fondamenti del serverless e confronto tra architetture
4. Casi d'uso reali e analisi dei costi
5. Limitazioni, anti-pattern e buone pratiche
6. AWS Lambda - funzioni, handler, cold/warm start
7. Trigger Lambda, sorgenti di eventi e supporto multi-linguaggio
8. Risorse Lambda, memoria, timeout e monitoraggio
9. Sicurezza - ruoli IAM, policy, minimo privilegio
10. Amazon API Gateway - API REST, integrazione proxy, CORS
11. Integrazione avanzata, Lambda authorizer, Cognito
12. Versioni delle API, stage e monitoraggio
13. Caching, tracciamento X-Ray e ripasso
14. Amazon DynamoDB - tabelle, chiavi, query, scan
15. DynamoDB Streams, integrazione con S3, GSI
16. Trigger S3, pipeline di import CSV, persistenza
17. TTL, backup, Point-in-Time Recovery
18. AWS Step Functions - macchine a stati, Workflow Studio
19. Gestione degli errori, Retry, Catch, stati di fallback
20. Orchestrazione multi-servizio e integrazioni dirette con gli SDK
21. AWS SAM - template, CLI, test in locale, deploy
22. CloudFormation, deploy automatizzati, CloudWatch
23. Governance dei costi, esame finale e chiusura del corso
