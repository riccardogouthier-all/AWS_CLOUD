# Sicurezza con AWS

**Sicurezza con AWS** - Materiali completi del corso per imparare e applicare i controlli di sicurezza cloud su Amazon Web Services: IAM, crittografia, monitoraggio, filtri di rete, rilevamento delle minacce, gestione dei segreti e backup.

## 📖 Argomenti trattati

Questa repository contiene i laboratori pratici di un corso di 48 ore sulla **sicurezza AWS**. I materiali sono pensati per l'apprendimento pratico della sicurezza cloud nel Learner Lab di AWS Academy.

I permessi del Learner Lab e le regole di pulizia sono riassunti qui: [permessi_learner_lab](permessi_learner_lab.md).

1. Fondamenti di sicurezza: responsabilità condivisa, flusso dei dati, confini di fiducia
2. Regioni e zone di disponibilità, crittografia dei dati
3. Compliance, AWS KMS e gestione delle identità
4. IAM: buone pratiche, MFA e policy JSON
5. SCP (Service Control Policy) e analisi degli accessi con IAM Access Analyzer
6. VPC, Security Group e Network ACL
7. Connessioni sicure (VPN, Direct Connect) e CloudTrail
8. CloudWatch e AWS Config
9. WAF, Shield e gestione dei segreti
10. GuardDuty e Inspector
11. Backup e ripristino sicuro
